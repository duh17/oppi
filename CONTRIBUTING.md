# Contributing to Oppi

Oppi is mainly a personal project, so I prefer discussing changes before anyone spends time implementing them.

If you find a bug or have an idea, [open an issue](https://github.com/duh17/oppi/issues/new) first. Keep it short and concrete: describe the problem or suggestion, explain why it matters, and include reproduction steps when relevant. We can define the behavior and scope there.

For now, do not open a pull request unless we discussed it in an issue and I asked for one.
