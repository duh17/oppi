# Contributing to Oppi

Oppi is still mainly a personal project, so right now I would rather discuss changes before anyone spends time implementing them.

If you find a bug or have an idea, please [open an issue](https://github.com/duh17/oppi/issues/new) first. Keep it short and concrete: describe the problem or suggestion, explain why it matters, and include reproduction steps when relevant. We can figure out the behavior and scope together there.

For now, please do not open a pull request unless we have discussed it in an issue and I have asked for one.
