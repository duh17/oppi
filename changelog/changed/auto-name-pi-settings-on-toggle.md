- **Server:** `oppi serve` no longer adds the bundled Auto-Name package to Pi's `~/.pi/agent/settings.json`. Auto-Name still shows, off, in **Extensions**; turning it on adds the entry, and turning it off removes it. At start, the server removes the off entry older servers added, so terminal `pi` no longer lists a package you never turned on. See [Auto-Name](docs/extensions.md#auto-name).
