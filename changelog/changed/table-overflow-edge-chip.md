- **Client:** A Markdown table wider than the screen now says so on its right edge: the edge fades and a small chip on the header row counts the columns out of view, such as **+3**. The table scrolls sideways, the count follows as you scroll, and a tap on the chip opens the table full screen. The bar under a table now appears only when a long table folds its rows, and reads **Show N more rows**; a table cut only at its edge no longer adds a **Show all N columns** bar.
