- **Client:** A Git diff opened from a review or a commit has **Viewing Options** in its bar, and a review's **Previous File** and **Next File** are bar buttons too, as in the file viewer. Nothing floats over the diff except the staged-comments button. **Settings → Editor → Reader Bar** arranges a review's buttons like any reader's, and a button you turn off moves into the **…** menu. See [The reader's bar](docs/document-viewers.md#the-readers-bar).
