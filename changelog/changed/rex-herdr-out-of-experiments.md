- **Client:** Rex and Herdr are no longer experiments: their switches are gone from **Settings → Experiments**, and both are on wherever the server offers them. Each server turns them on or off for every device in **Server Settings → Features**. Rex no longer needs Terminal there: a server with Terminal off and Rex on shows **Rex** in the sidebar without **Terminal**. Herdr still needs Terminal, and its terminal button can be turned off in **Customize Bar…**. See [Features](docs/server-configuration.md#features).
