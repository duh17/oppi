- **Client:** In the SSH terminal, files, folders, and web pages open where a link tapped in a chat opens: on a wide iPad window with Split Panes on, that is a pane beside the terminal, and the terminal is never replaced. On iPhone and narrow windows they open as before. An OSC 8 link to a path, such as the file links pi prints (`[the event ring](server/src/session-broadcast.ts#L194)`), now opens: the path can be relative to the shell's folder, absolute, `~/…`, or a `file://` address on the same machine, and the file opens at the link's line (`#L194`, `:194`, or `:194:5`). Before, only web links opened. A plain path such as `src/x.swift:42` now opens at line 42 too. Tap a link, a URL, or a path the terminal can open to open it; a double tap still copies the word, and a program that takes mouse clicks still gets the tap. Touch and hold a link for **Open Here**, **Open in New Pane to the Right**, and **Open in New Pane Below**, as in a chat. See [Links, paths, and the shell's folder](docs/ssh-terminal.md#links-paths-and-the-shells-folder).
