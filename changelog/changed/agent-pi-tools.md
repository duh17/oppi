- **Client:** A saved Agent's **Tools** section has a **Pi Tools** row that opens the same page as Pi's own: the same built-in Pi tools, `codemode`, `tool_search`, and the tools extensions register off, with **Pi defaults** (the server's Pi Tools setting) or an exact set for that Agent. An Agent can therefore be given codemode, with or without an MCP server. **Edit files** is gone as a switch: an Agent cannot change files when its tools leave out `edit` and `write`, and such an Agent still names the plugins and MCP servers it may use. The Agent's page shows its Pi tools and whether it edits files.
