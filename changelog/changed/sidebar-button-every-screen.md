- **Client:** On iPad, the sidebar button is on every screen of the main pane, not only the first: a chat opened from Agents, Schedules or Pinned, a file reader, and a terminal, including one opened from the Rex list. In portrait it opens the sidebar over the screen you are on, and a place you pick there replaces that screen. On iPhone it stays on **All Sessions**. See [Screen map](docs/usage.md#screen-map).
