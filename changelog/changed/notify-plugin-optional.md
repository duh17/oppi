- **Server:** The agent's `notify` tool is now an ordinary built-in plugin, `oppi-notify`. It is still on by default and still offered only to top-level sessions while a device has push on, but its row in **Server Settings → Extensions** (or `oppi extensions disable oppi-notify`) now turns it off for durable and classic sessions. A plugin of your own can send the same push with `oppiHost().notify(api.env)` from `oppi/v1`, under the same limits, whether `oppi-notify` is on or off; `NotifyInput` and `NotifyOutcome` are exported for typing it. See [Plugins](docs/extensions.md#plugins).
