- **Server:** Attachments no longer have a 50 MB size limit; the only limit is free disk space. The server refuses an upload only when it would leave less than 2 GB, or 5% of the disk, free, and the error says how much space is free. `uploadStore.maxFileBytes` and `uploadStore.maxTurnBytes` remain as optional caps. Configs that still carry the old 50 MB and 100 MB defaults lose them when the server loads the config.
- **Client:** Large attachments, such as screen recordings, upload from the file on disk instead of from memory. The upload keeps going while Oppi is in the background or the screen is locked, unless it runs through Oppi's built-in Tailscale connection; there the composer says "Paused — keep Oppi open to finish" and the upload resumes when you come back. Each attachment shows its own progress, and one line with a progress bar shows the whole send. Tap the X on an uploading file to cancel; a failed or cancelled file offers Retry and Remove, and your message stays in the composer. Files that already finished are not uploaded again. If the connection drops, Oppi resends the file, and if every attempt fails, it shows why.
