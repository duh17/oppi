- **Server:** Runs on Pi 1.6.0. In durable sessions, code mode lists each MCP server as its own namespace (`mcp__<server>`) from the first message, with the first line of the server's configured `description`, also a server that is still connecting or waiting for sign-in; scripts can call `describeNamespace("mcp__<server>")` and `searchTools(query, { namespace })` for one server. MCP tool names do not change.
- **Server:** In durable sessions, the time shown for each tool call inside a code mode script now runs from the call's start to its result, including any time the server was down or restarting in between.
