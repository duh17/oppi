- **Client:** An Agent or workspace icon is a PNG or an animated WebP; GIF is no longer an icon format. Picking a GIF in the icon picker says so and asks for WebP, and an animated PNG holds still. Only WebP plays, on the Agent's page, on its row in the Agents list, in the icon picker, and for a moment on a session row whose session needs you. See [Animated icons](docs/usage.md#animated-icons).
- **Server:** `POST /icon-assets` and `--icon-image` refuse a GIF with a message that names WebP. A GIF uploaded before this keeps serving, and its icon holds still. See [Animated icons](docs/usage.md#animated-icons).
