- **Protocol:** A saved Agent's `capabilities.core` (`full` | `readonly`) is replaced by `capabilities.tools`, the Pi tools its sessions start with; omitted follows the Pi Tools setting. `codemode` and `tool_search` are honored when an Agent names them, and an MCP server that needs one still turns it on. `/server/info` reports `agentCapabilities` version 2, and an app that does not know it shows saved Agents read-only. Every Agent keeps the tools it could use before: the server rewrote each stored Agent and its version history once at startup, under a database backup, and logged every row it changed.
