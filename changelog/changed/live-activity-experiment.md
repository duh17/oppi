- **Client:** Live Activities are now an experiment, off by default. The **Live Activities** switch in Server Settings → Notifications shows only while **Settings → Experiments → Live Activity** is on. While it is off, no card shows, a running card ends, and the app tells each server it shows no card, so servers send no card pushes. Each server's choice is kept and comes back when the experiment is turned on. See [Live Activity](docs/server-configuration.md#live-activity).
