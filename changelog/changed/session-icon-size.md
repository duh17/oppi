- **Client:** **Settings → Session Rows → Session Icons** sets how big a session's icon draws in every session list: **Small** (32 pt, the default and what rows drew before), **Medium** (44 pt), or **Large** (56 pt). The row's text column, a thread's child indents, and the row's height follow the size, and a list open under Settings redraws where it is. The Session Rows preview above the controls is the real row, so each size shows before you leave the page. See [Session rows](docs/usage.md#session-rows).
