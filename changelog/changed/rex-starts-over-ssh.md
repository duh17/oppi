- **Client:** Over SSH, Oppi now reaches Rex through Rex's own bridge (`rex __internal dial-stdio`) and starts your Rex server on a host only when you ask for it there: opening a Rex pane on the host, **New Session** for it, or tapping **Start Rex** under **Rex is not running** in its Rex section. The host's `REX_AUTOSTART=0` still keeps Rex stopped. Opening the Rex screen, a Rex section, or a Rex host's screen only reads, so it never starts Rex on any saved host, and neither does a plain terminal reading Rex in the background. Oppi finds `rex` in `~/.local/bin`, on the `PATH` that SSH commands see, or in the newest server the Rex Mac app installs, so a Mac with only the Rex app needs no setup. The host no longer needs `netcat-openbsd`; `nc -U` is only a fallback for a Rex too old to have the bridge. See [Starting Rex](docs/ssh-terminal.md#starting-rex).
