- **Client:** Over SSH, Oppi now reaches Rex through Rex's own bridge (`rex __internal dial-stdio`) and starts your Rex server on the host when it is not running, as Rex's own apps do, unless the host sets `REX_AUTOSTART=0`. As with Rex's own apps, `rex` must be in `~/.local/bin` or on the `PATH` that SSH commands see. The host no longer needs `netcat-openbsd`; `nc -U` is only a fallback for a Rex too old to have the bridge. A plain terminal reading Rex in the background never starts it. See [Starting Rex](docs/ssh-terminal.md#starting-rex).
