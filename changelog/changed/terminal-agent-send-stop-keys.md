- **Client:** While a coding agent reports its status in the SSH terminal, a Return key on the bottom bar or keyboard bar shows as the chat's **Send**, and while the agent works, the key its keymap binds to interrupt (Esc for pi, Claude Code, and Codex) shows as the chat's **Stop**. The keys send the same bytes as before, and return to plain Return and Esc for the shell. See [Program shortcuts](docs/ssh-terminal.md#program-shortcuts).
