- **Client:** On a wide iPad window with Split Panes on, a file, folder, or web link you tap in a chat opens beside the chat: a file in the chat's side column, as a tapped file pill opens, a folder in **Files** at that folder, a web page in a web page pane. A folder or web page reuses a pane that already shows that kind of thing, or an empty **New Pane**, before it opens a new pane, which goes to the right in landscape and below in portrait; a later new pane splits the pane beside the chat, so the chat keeps its room. The chat, terminals, and Rex are never replaced. Folder links (such as `[src](src/)`) now open at all; before, they could not be resolved. Touch and hold a link for **Open in New Pane to the Right**, **Open in New Pane Below**, and **Open Here** (the main pane). iPhone and narrow windows open links as before. See [Split panes](docs/usage.md#the-ipad-side-column).
