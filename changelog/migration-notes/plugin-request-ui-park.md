- **Plugins:** `requestUI` from `oppi/v1` no longer waits for the answer. It returns `{ park }`, and returns `{ response }` when the caller runs again after the answer or the timeout. A tool returns the park from `execute()` and adds `cancel: withdrawUI`, so that a stopped call closes its dialog. A `beforeTool` hook returns `{ sleep: park.sleep }`. A run after the answer must pass an explicit `key` to `api.executeTool` and `api.createTask`. A plugin that is not updated still loads, but it gets no answer, and its dialog stays open; nothing reports the error. See [Plugins](docs/extensions.md#plugins).
