- **Protocol:** Pins are now saved pane routes (pins v3). This app shows no **Pin** items and no **Pinned** screen with a server older than this release, and an app older than this release can't read the pins of a server of this release. The server reads the folder and file pins an older server saved and keeps them; it writes them in the new form on the next change, after which an older server can't read them.
