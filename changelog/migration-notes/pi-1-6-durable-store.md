- **Compatibility:** pi-durable 1.6.0 writes tool and generation tasks in a newer format that an `oppi-server` on pi-durable 1.5.2 (0.55.0) cannot run. After a downgrade, a durable session that was working or waiting when the server stopped stays blocked. Downgrade only while every durable session is idle, or back up `$OPPI_DATA_DIR/durable/sessions/` first. Classic sessions are unaffected.
