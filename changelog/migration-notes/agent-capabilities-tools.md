- **Agents:** A saved Agent's `capabilities.core` (`full` | `readonly`) is replaced by `capabilities.tools`, the Pi tools its sessions start with (`["read","bash"]`, `["read","bash","codemode"]`, or omitted to follow the Pi Tools setting). The server rewrote every stored Agent and its version history once at startup from the coding tier it held: a `full` Agent follows the Pi Tools setting as before, and a `readonly` Agent states that setting's tools without `edit`, `write`, `codemode`, or `tool_search` — `codemode` and `tool_search` still arrive from an MCP server it names that needs them. A backup of the database is written first, and each changed row is logged. `oppi agent --core` is gone; use `--tools all|none|csv`.
