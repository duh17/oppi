- **Client:** A tapped link always opens something or says why it can't. `history://<id>` and `agent://<id>` in a chat, tool row, or reader open that session, by full ID or unique prefix. `mcp://` and `ssh://` links, a `proc://` link outside a chat, and any `oppi://` route the app does not know show a message instead of doing nothing. An unknown `oppi://` route no longer starts pairing. A session link to a session older than the session list opens after a lookup on its server instead of doing nothing. See [Deep links](docs/deeplinks.md#links-in-assistant-output).
