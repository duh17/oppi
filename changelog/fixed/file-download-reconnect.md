- **Client:** A file download for Share, Save to Files, or Quick Look shows **Reconnecting** while a dropped connection waits, and continues at the server's new address after the route changes (Wi-Fi to Tailscale, a new Tailscale proxy). It keeps retrying as long as each attempt moves bytes, and when it stops it says why: offline, server unreachable, file not found, outside the shared folders, too large, or out of space.
