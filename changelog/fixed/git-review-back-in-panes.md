- **Client:** On iPad, a changed file opened from the Git panel keeps its **Back** button beside **Files**, so it always returns to the Git list. Before, when more than one file had changed, **Files** took Back's place and there was no way back.
- **Client:** On iPad, a file, commit, or commit file tapped in a Git pane, such as a linked Git opened beside another pane, now opens in that pane with **Back**. Before, a changed file opened in a sheet over every pane.
- **Client:** On iPad, when a chat's panel covers the chat in a pane below another, the pane's grip now sits under the panel's bar instead of over its first row, such as the Git branch or a diff's file name.
- **Client:** On iPad, the Git panel's file and commit rows use a larger text size, the same size as the diff they open, including in the chat's Git panel.
- **Client:** A linked Git pane no longer stays on "Loading Git status…". It loads its own status when it appears, including right after the app relaunches. If loading fails, it shows the error with **Retry**, and it refreshes when the connection comes back. Before, opening a chat or a workspace in another pane could leave the Git pane loading forever.
