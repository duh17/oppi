- **Server:** A plugin panel (`surface()` from `oppi/v1`) keeps its state per chat, so a tap in one chat no longer runs over, or redraws, another chat's panel. A panel's action can now save to the plugin's documents with `conversation.commit`, and a panel listed in `defineExtension({ surfaces })` is drawn again when its chat reopens after a server restart. See [A panel plugin](docs/extension-native-ui.md#a-panel-plugin).
