- **Server:** The server no longer freezes for seconds at a time while the disk is busy (a build, a test run, or a worktree cleanup), which made any screen's request time out. Listing a workspace's sessions used to look up every stored session's file on disk before answering, holding up every other request; on a server with thousands of sessions that took 0.4–2.7 s on a quiet disk and up to 10 s on a busy one. Those lookups now run in the background and are remembered, so a session list answers in milliseconds and other requests keep flowing.
