- **Client:** The Godot pane no longer asks you to quit and reopen Oppi. Opening another game ends the one playing and starts it in its pane, and the first game's pane offers **Play** to switch back. A build that changes project settings or autoloads starts its game again, and **Play** starts a game again after it quits.
- **Client:** **Reload** in the Godot pane no longer fails with "The scene didn't reload" when the game is paused right after a new build or an earlier Reload, and **Retry** on "The Game Didn't Load" now starts the game again instead of leaving the message up.
