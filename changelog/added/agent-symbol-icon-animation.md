- **Client:** A saved Agent's or a workspace's SF Symbol icon can animate. Choose **Bounce**, **Pulse**, **Breathe**, **Wiggle**, or **Rotate** under **Animation** in the icon picker, which previews it live. Like an animated image, it plays on its own page (the Agent's page; a workspace's Workspace Settings and Details), in the picker, and for a moment on a chat's icon and on a session row that needs you. **Settings → Chat → Motion**, Reduce Motion, or Low Power Mode can hold it still.
- **Server:** A symbol `IconChoice` takes an optional `effect`: `{"kind":"symbol","name":"sparkles","effect":"bounce"}`, one of `bounce`, `pulse`, `breathe`, `wiggle`, or `rotate`. Any other value is refused. An app that does not know an effect draws the symbol still.
