- **Client:** A saved Agent's SF Symbol icon can animate. Choose **Bounce**, **Pulse**, **Breathe**, **Wiggle**, or **Rotate** under **Animation** in the Agent icon picker, which previews it live. Like an animated image, it plays only on the Agent's page and in the picker, and Reduce Motion or Low Power Mode keeps it still.
- **Server:** A symbol `IconChoice` takes an optional `effect`: `{"kind":"symbol","name":"sparkles","effect":"bounce"}`, one of `bounce`, `pulse`, `breathe`, `wiggle`, or `rotate`. Any other value is refused. An app that does not know an effect draws the symbol still.
