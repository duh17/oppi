- **Server:** Three example plugins ship with the server, turned off: `example-release-notes` (a tool that runs a command and returns its output), `example-bookmarks` (tools whose state survives a restart), and `example-board` (a panel with a pill, a drawer, and a button that saves). Turn one on with `oppi extensions enable <name>` or in **Server Settings → Extensions**; a durable session then offers its tools. See [Example plugins](docs/extensions.md#example-plugins).
