- **Server:** Server Settings → **Features** turns larger features off for every device that uses the server: Agents, Schedules, Skills, Extensions, MCP Servers, Terminal, Rex, Herdr, Godot Pane, and Web Pages in Panes. **Plain Pi** turns them all off, leaving chat, sessions and files; MCP off also stops new sessions loading MCP servers, and Schedules off pauses every schedule (slots missed while off are skipped). `oppi config set features plainPi` does the same from the host. See [Features](docs/server-configuration.md#features).
- **Client:** A feature the server turns off leaves the sidebar, new panes, the chat bar and Quick Session, and its links say it is turned off on this server. Agents, Skills, Extensions and the Godot Pane only hide their screens: sessions still use installed skills and extensions. Apps follow a change without reconnecting.
