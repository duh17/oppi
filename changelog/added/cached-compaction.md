- **Server:** A new built-in plugin, `cached-compaction`, ships turned off. In a durable session it makes `/compact` and automatic compactions summarize through the conversation's own cached request while the provider's prompt cache is still warm, so the older history is read from the cache instead of billed again as new input. Turn it on with `oppi extensions enable cached-compaction` or in **Server Settings → Extensions**. See [Cached compaction](docs/extensions.md#cached-compaction).
