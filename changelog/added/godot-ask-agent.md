- **Client:** The Godot pane hands the game to the chat beside it. **Ask Agent** on a game's error puts a draft in the chat's composer with the game's name and release, the error with its file, line and backtrace, the log's recent errors, and the current frame as an image; add your words and send. **More › Send Frame to Chat** does the same with the frame alone. Neither sends by itself, and both show only while a chat can take the draft. See [Hand a game to the chat](docs/godot.md#hand-a-game-to-the-chat).
