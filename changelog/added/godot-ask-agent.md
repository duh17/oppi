- **Client:** The Godot pane hands the game to the chat beside it. **Ask Agent** on a game's error puts a draft in the chat's composer with the game's name and release, the error with its file, line and backtrace, the log's recent errors, and the current frame as an image; add your words and send. **Snapshot to Chat** in the pane's bar does the same for a game without an error: the current frame with the game's scene, whether it is playing or paused, its view size, its frame rate, and its recent log. Neither sends by itself, and both show only while a chat can take the draft. See [Hand a game to the chat](docs/godot.md#hand-a-game-to-the-chat).
