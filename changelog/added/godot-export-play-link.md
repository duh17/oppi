- **Server:** A web build from `godot_export` now comes with a play link that is valid for 24 hours. The link opens that one build in Oppi's browser pane or in any browser that can reach your server, with no sign-in. It opens nothing else, and an expired or changed link gets "not found". Web builds now download brotli- or gzip-compressed, so the engine's 39.5 MB `.wasm` arrives as about 8 MB. See [Play outside the pane](docs/godot.md#play-outside-the-pane).
- **Client:** The browser pane opens a Godot web build's play link, though it is at a paired server's address. Every other page at that address stays refused, and the pane never sends Oppi's credentials.
