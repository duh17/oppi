- **Server:** `oppi uninstall` removes Oppi from a Mac or Linux machine: the background service, a server the installer started without one, Linux lingering if Oppi turned it on, Oppi's Auto-Name entry in Pi's settings, the `PATH` line the installer added to your shell profile, the `~/.local/bin/oppi` link, and `~/.oppi`. It asks before it deletes the data folder with your chats, settings, and paired devices; `--delete-data` and `--keep-data` answer in advance. `oppi server uninstall` still removes only the service. See [Uninstall Oppi](docs/uninstall.md).
- **Server:** The installer keeps npm's cache in `~/.oppi`, and the server's update check uses a temporary npm cache, so neither creates `~/.npm` on a machine without npm of its own.
