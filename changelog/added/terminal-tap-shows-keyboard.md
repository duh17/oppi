- **Client:** **Settings → Terminal → Tap in Terminal** chooses what a tap on the SSH terminal does: **Keyboard Button Only** (the default, as before) starts typing only from **Type in Terminal** on the bottom bar, and **Tap Shows Keyboard** raises the keyboard with a tap. Either way, a tap on a link opens it, a program that takes mouse clicks (tmux, Herdr) gets the tap, and a double tap copies the word. See [Touch](docs/ssh-terminal.md#touch).
