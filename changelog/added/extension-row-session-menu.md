- **Client:** A row of a composable surface that opens a session now offers that session's menu on touch and hold, secondary click, and as accessibility actions — **Open**, **Copy Branch** when it works in a worktree, **Copy Session ID**, and **Stop** while it runs — the same menu an activity row linked to a session has offered. The row itself still opens the session on a tap, and the buttons inside it keep their own touches.
- **Client:** One difference from an activity row: a tree row carries no state of its own, so **Stop** is decided by the session alone. A failed child whose session has already stopped no longer offers **Stop** there, which an activity row did; the subagents pill's **Dismiss** replaces it, and stops nothing.
