- **Server:** When a Godot game gets a new release, the server checks its scripts for APIs that desktop Godot still has but the Godot pane's engine leaves out, such as `Image.create`. Each use is logged as an error of the release with its file, line, and what to use instead, so `godot_status` and `godot_logs` show it before the game fails on the device. The release still plays. See [APIs the device does not have](docs/godot.md#apis-the-device-does-not-have).
