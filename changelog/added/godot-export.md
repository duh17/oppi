- **Server:** A new agent tool, `godot_export`, builds a game in a workspace to play outside the Godot pane. A web build is served by your Oppi server at `/godot/<game>/web/<build>/`, only to the owner and paired devices. macOS (a zipped, ad-hoc signed app), Linux, and Windows builds go into the project's `build/` folder. The project's `export_presets.cfg` stays unchanged. Godot's export templates are installed only when the agent asks: the server downloads them one time per Godot version from the official release and checks them against the published SHA-512 sums. iOS and Android are not targets. See [Play outside the pane](docs/godot.md#play-outside-the-pane).
