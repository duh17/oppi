- **Client:** A saved Agent's or a workspace's icon can now be an image you import from Photos or Files, next to emoji, SF Symbols, and Genmoji. Agents and workspaces use the same icon picker; only its title and symbol heading differ. A still photo is scaled down to a small PNG before it uploads; an animated PNG, GIF, or WebP of up to 1 MB uploads as it is. An animated icon plays only on its own page (the Agent's page; a workspace's Workspace Settings and Details) and in the icon picker, and shows its first frame everywhere else (Agent and workspace lists, the sidebar, sessions, menus, schedules). A sandbox workspace keeps its lock mark while its icon plays. Reduce Motion, Low Power Mode, or turning off Auto-Play Animated Images keeps it still.
- **Server:** Icon assets now also take PNG (including APNG), GIF, and WebP images of up to 1 MB and 1,024 pixels on a side, stored with Genmoji in the same icon store. The server reads the format from the bytes and ignores the declared `Content-Type`. A new `IconChoice` kind, `{"kind":"image","assetId":"ia_…"}`, names an imported image; an Agent or workspace icon must name an asset of its own kind, so a Genmoji cannot point at an image or the reverse.
- **Server:** `oppi agent create|update --icon-image <file>` and `oppi workspace create|update --icon-image <file>` set an image icon from a file on the server, with no phone involved. The file goes through the same icon upload as the app, so an image that is too big or is not a PNG, GIF, or WebP is refused with the reason. Oppi Control's `agents_create` and `agents_update` tools take the same path as `iconImage`; the owner confirms the upload on a card that names the file.
