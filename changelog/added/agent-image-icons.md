- **Client:** A saved Agent's icon can now be an image you import from Photos or Files, next to emoji, SF Symbols, and Genmoji in the Agent icon picker. A still photo is scaled down to a small PNG before it uploads; an animated PNG, GIF, or WebP of up to 1 MB uploads as it is. An animated icon plays only on the Agent's page and in the icon picker, and shows its first frame everywhere else (Agent list, sessions, menus, schedules). Reduce Motion, Low Power Mode, or turning off Auto-Play Animated Images keeps it still.
- **Server:** Icon assets now also take PNG (including APNG), GIF, and WebP images of up to 1 MB and 1,024 pixels on a side, stored with Genmoji in the same icon store. The server reads the format from the bytes and ignores the declared `Content-Type`. A new `IconChoice` kind, `{"kind":"image","assetId":"ia_…"}`, names an imported image; an Agent or workspace icon must name an asset of its own kind, so a Genmoji cannot point at an image or the reverse.
